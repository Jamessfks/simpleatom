## Science: independent recomputation

The `science-critic` agent (this session's new `.claude/agents/science-critic.md`, run as a
general-purpose subagent with that file as its prompt) recomputed eight golden cases in its
own scripts, which import only ase, numpy, torch and `mace.calculators`. Stack: Python
3.11.15, torch 2.10.0, mace-torch 0.3.16, ASE 3.27.0, on an Apple M4 Pro at 1 and 2 threads.
**Run-to-run noise was zero:** SimpleAtom's 6 repeats at `OMP_NUM_THREADS` 1 and 2 and the
critic's repeats agree bitwise, so tolerances fall back to the 64·eps·|value| floor, and MD
is judged against block standard errors. Full report:
`docs/v2/evidence/2026-10-28/reviews/science-critic-golden.md`.

| Case | Verdict |
|---|---|
| Ethanol and water single point, MACE-OFF small | E, E/atom, max\|F\|, RMS F (÷N), ΣF match (Δ = 0) |
| `silicon.cif`, MPA-0 and MP-0 single point | E and forces Δ = 0; stress symmetric, Voigt order and −trace/3 correct, ASE sign confirmed by finite difference; every nearest neighbour 2.351649 Å, coordination 4 |
| Invariants | translation by 0, 10 and 100 Å and a seeded random rotation leave E unchanged and rotate F covariantly; the 2×2×2 Si supercell gives exactly 8× the energy |
| Ethanol geometry opt (fmax 0.01) | final max\|F\| 0.0092253 < 0.01, "converged" is correct; same 61 BFGS steps; D5 frame duplication fixed |
| NVE ethanol (0.5 fs, 2000 steps) | fitted drift −5.2 × 10⁻⁶ eV/atom/ps |
| NVT ethanol (300 K) | ⟨T⟩ = 290.2 ± 18.6 K (27 dof); over 5 seeds 298.3 ± 6.7 K. With `fixcm=True` the critic gets 431 K, so the D18 fix holds |
| NPT Si (MPA-0) | `pfactor` = (75 fs)² × 100 GPa = 33.8745 ASE units; ⟨P⟩ = 0.04 ± 0.04 GPa |
| Units, engine to UI | no missing conversion found (traced by reading; UI labels not checked in a rendered page) |
