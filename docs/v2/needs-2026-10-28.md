## 0. Method, limits, and what could not be verified

**Usage analytics.** None are available to this research, and no usage numbers appear below. Vercel Web Analytics and Speed Insights are mounted (`app/layout.tsx:3-4`, `app/layout.tsx:75-76`; `package.json:18-19`), and the app has no custom events (`grep "track("` returns 0 hits). The owner can pull two proxies that I cannot reach. First, page views per route (`/calculate`, `/benchmark`, `/docs/*`, `/r/[id]`) from the Vercel dashboard. Second, counts of shared results grouped by `params.calculationType` and `params.modelType` in the Supabase `shared_results` table (`supabase/migrations/0001_shared_results.sql`).

**What the evidence is.** There is no direct user research on SimpleAtom users. Everything external is demand among *MACE-library and ASE users* (a developer-skewed population), read as a proxy. Counts are lower bounds. They come from keyword screening plus manual reading of the thread titles and first posts.

**Fetch methods (all 2026-10-28).**
- GitHub threads were fetched with `gh` (GraphQL and `gh issue view`). I downloaded all 436 discussions and 696 issues of `ACEsuit/mace` and screened them locally. 72 maintainer roadmap issues (titles like `DEP-1 —`) were excluded, leaving 624 issues. One thread (D#718) was cross-checked with WebFetch.
- Web pages came from WebFetch, `tavily_extract`, or `tavily_search`. Where a page was seen only as a search snippet, the evidence index says so ("snippet").
- Matter Modeling Stack Exchange (MM SE) items are snippet-level reads. I did not read every answer.

**Not found, and how to verify.**
- The README has **no "Why this exists" section**. The nearest passages are "What it does" (`README.md:19-36`) and "What it is not" (`README.md:38-42`).
- MM SE returned **no question about running MACE foundation models as a workflow**. The MM SE evidence is about the same workflows in ASE or DFT, and it transfers by analogy only. To verify, run a manual site search for "mace-mp" and "foundation model".
- Rowan's `/workflows` page returned 404, and its docs home page lists no workflows. Rowan evidence is limited to the home page. To verify, open `https://rowansci.com` in a browser and read its workflow list.
- The Schrödinger page is generic. It names DFT, xTB, QM, conformation search, MD, informatics and ML, and does not name optimisation, thermochemistry or reaction paths. It is used for breadth only.
- No axe or screen-reader run exists for the app. The accessibility gaps in row 15 are code-read only (UNVERIFIED). To verify, run axe DevTools plus VoiceOver/NVDA on `/calculate` after a result.
- Class-scale capacity on the hosted single CPU (row 12) is UNVERIFIED. To verify, run N concurrent single-point jobs against the hosted Space.
