**Tie-break.** The two leaders tie at 42. Ties go to the two criteria that decide whether a

## Recommendation

Build **harmonic vibrations + ideal-gas thermochemistry for isolated molecules**
([ADR-0032](../adr/0032-molecular-vibrations-thermochemistry.md)). It is reached by one
chain step: "Compute frequencies" on a converged geometry optimisation. Ship it with
**device honesty** ([ADR-0031](../adr/0031-device-honesty.md)) and **Feedback**
([ADR-0033](../adr/0033-feedback-by-email.md)). Cell relaxation + EOS is the next piece. It
needs its own ADR and is not part of this plan.

### The strongest argument against

SimpleAtom's default model is the materials model MACE-MPA-0 (MIT). Cell relaxation fixes a
visible inconsistency: v2.2 reports stress but cannot relax the cell that produces it. It
takes seconds on `cpu-basic`, it is the item the last audit left open, and it serves the
default model's own audience. Vibrations, by contrast, are best served by MACE-OFF23, which
is **ASL and non-commercial**. The flagship addition would therefore lean on a model that
commercial users may not run. Harmonic frequencies are also 3–5 % above the fundamentals
people quote, so the feature invites a misreading (water's OH stretch: 3844 harmonic vs
3657 fundamental).

**Why the recommendation stands anyway.**

* The licence notice already ships on every MACE-OFF result (U5), and MP-family molecular
  frequencies run with a warning, not a refusal.
* The UI labels frequencies "harmonic" and puts the expected-gap column next to them.
* Cell relaxation is still the very next piece, and it is cheap enough to follow within days.

## What can run in parallel

* **Track 0 (containment) is a prerequisite for any production verification** and is owned by

  1.3.0.

  the link is rebased in.

  sequence, contract first, with one writer per file set, each in its own worktree.
  `science-critic` and `design-critic` are separate, fresh-context critics.
